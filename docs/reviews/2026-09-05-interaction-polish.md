# 2026-09-05 交互打磨第一批

基线：`a5e4719`，已安装的 2.1.2 (41)。仅保留听写、问答、Agent；不恢复旧的 X Reply 或 Prompt Studio。

## 已实现的规则

- 会话内麦克风在开始时捕获会话 ID 和模式；忽略全局模式、其他浮层和复核选择。识别期间切换会话不改变目标。再次点击同一会话的停止按钮结束录音。取消与失败清除捕获目标。
- 会话语音不解析全局的语音模式切换前缀，与文字发送遵守同一个会话归属；全局快捷键行为不变。
- 会话输入框按问答 / Agent 显示文案，不再硬编码 Option。
- 听写页、来源筛选、搜索、导出、侧栏数量只统计 `transcribe`；共享事件库不删除或迁移，问答 / Agent 仍在会话页。成功加载但只有非听写记录时显示真正的听写空状态；加载失败不冒充空历史。
- 全模式统计保留在默认收起的「使用情况 · 所有模式」中。复制、重新使用增大可点击面积并提高可见度。
- 普通成功浮层不重复已写入的正文。带纠错提示的普通成功浮层最多停留两秒，纠错本身仍遵守原有时间窗。带词典撤销 / 学习操作的浮层保留原交互时间和正文，不缩短撤销机会。
- 问答和 Agent 默认跟随当前用户消息语言；问候一句话，不列能力清单；实质任务保留所需细节。Agent 明确区分草稿与已执行操作，不无凭据声称成功。

## 验证边界

2026-09-05：完整 Swift 回归 1104 XCTest + 13 Swift Testing 通过；sidecar 1378 项通过。

单元测试检查捕获目标、模式前缀、历史归属、空状态、浮层时长和系统提示约束。
真实模型的回答风格需要另外评估，提示词字符串通过不等于模型永远遵守。
